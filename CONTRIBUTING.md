# Contributing

Bug reports, questions and ideas are welcome through
[GitHub issues](https://github.com/IDX-Kit/idx-kit/issues).

Code contributions are not accepted. Pull requests are limited to
collaborators. Ideas may be implemented independently.

Run `npm run format` to format hand-written source files.
Run `npm run format:check` and `npm run lint` to check code before a pull request.

Do not include passwords, API keys, MLS credentials, or real client or lead
information in issues. Report vulnerabilities privately using
[SECURITY.md](SECURITY.md).
